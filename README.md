# Enterprise IT Asset Management System

## Overview

Enterprise web application developed with Laravel to manage IT assets, employee assignments, maintenance schedules, QR code tracking, and reporting.

---

## Features

- Secure authentication
- Role-based access control
- Asset inventory
- QR Code generation
- QR Scanner
- Employee assignments
- Maintenance tracking
- PDF reports
- Excel export
- Interactive dashboard

---

## Tech Stack

- Laravel
- PHP
- MySQL
- Bootstrap 5
- JavaScript
- Chart.js
- DomPDF
